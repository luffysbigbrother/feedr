How to get your credentials
1
Go to github.com and sign in or create a free account
2
Go to Settings → Developer Settings → Personal Access Tokens → Tokens (classic)
3
Click Generate new token, name it "Feedr", set expiration to No expiration, check only the gist scope
4
Copy the token — starts with ghp_ — and paste above. You only see it once
5
Go to gist.github.com, create a new Secret Gist, filename feedr-data.json, content {}
6
Copy the Gist ID from the URL (the long string after your username) and paste above
